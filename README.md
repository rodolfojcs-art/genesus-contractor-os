# Genesus Contractor OS — demo

Field operating system for electrical contractors. White-label build on the
Genesus IA engine, by Genesus Technology LLC.

**Demo with simulated data.** No backend, no database, no live systems: every
figure on screen is computed in the browser from a fixed seed.

Installable as an app: open the site on your phone and choose *Install* /
*Add to Home Screen*. It works offline after the first load.

This repository holds only the built site. The source is private.
